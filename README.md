# 🚀 Todyx — Task Planner

**Todyx** is a simple, modern, and intuitive task planner app for Android, built with **Kotlin** and **Jetpack Compose**. It helps users organize daily tasks, track progress, and stay productive with a clean Material 3 interface.

## ✨ Features

- ➕ **Add Tasks** — Create new tasks with titles and descriptions.
- ✏️ **Edit Tasks** — Update existing tasks whenever needed.
- 🗑️ **Delete Tasks** — Remove tasks you no longer need.
- ✅ **Task Completion** — Mark tasks as completed and track your progress.
- 💾 **Offline Storage** — Save tasks locally on your device using Room Database.
- 🎨 **Modern UI** — Clean and responsive interface built with Jetpack Compose and Material 3.
- 📱 **Native Android Experience** — Designed specifically for Android devices.

## 🚀 Getting Started

Follow these steps to run Todyx locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/acadlvv7-dev/REPO-NAME.git
```

### 2️⃣ Open the Project

Open the cloned project in **Android Studio**.

### 3️⃣ Sync Gradle

Wait for Gradle synchronization to complete and allow the required dependencies to download.

### 4️⃣ Run the App

Select an Android emulator or connect a physical Android device, then click **Run ▶️**.

## 📋 Requirements

- 🖥️ Android Studio — Latest stable version
- 📱 Android 7.0 (API 24) or higher
- ☕ Compatible JDK and Android SDK
- 🌐 Internet connection for the initial Gradle dependency download

## 🔒 Data & Privacy

- 🔐 No account or sign-in required.
- 💾 Tasks are stored locally on the device.
- 📡 No internet connection is required for core task management.

## 🎯 Project Goals

Todyx was built to practice and demonstrate modern Android development concepts, including:

- Clean separation of UI and data layers
- MVVM architecture
- Dependency injection with Hilt
- Local persistence with Room
- Reactive state management using Kotlin Flow
- Asynchronous programming with Coroutines
